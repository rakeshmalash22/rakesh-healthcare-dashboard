# 🏥 Healthcare Dashboard

A modern and responsive Healthcare Dashboard built using React.js. This project helps users monitor patient information, diagnosis history, vital signs, and healthcare statistics through a clean and interactive dashboard.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/rakeshmalash22/rakesh-healthcare-dashboard.git
```

Move into the project

```bash
cd rakesh-healthcare-dashboard
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm start
```

Build for production

```bash
npm run build
```
